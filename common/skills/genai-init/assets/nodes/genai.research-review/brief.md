# Rule on it

The question was asked to change a decision. This is where that happens, or where it turns out it
cannot yet.

Read the proposal first, then the report. If the proposal does not stand up, the report is not going
to rescue it.

Three ways this goes:

- **Approved** — the decision it implies is now made. Record what was decided, not just that the
  document was acceptable.
- **Conditional** — treated as a reject here. A condition attached and not addressed is a condition
  unmet, and acting on the proposal anyway is the failure this gate exists to prevent.
- **Rejected** — it does not answer what was asked. This routes back to the **question**, not to the
  writing, because a synthesis that misses the question is usually evidence the question was wrong.
  Say which part went unanswered; that sentence is what reshapes it.
